# Правила работы

1. Работай строго по фазам из `ai-vtuber-plan.md`. Не начинай следующую, пока пользователь не подтвердил «готово» текущей.
2. В конце каждой фазы: покажи команды проверки, ожидаемый результат, что именно запускать.
3. Любые установки системных пакетов, замену quickshell на форк, правку конфигов driftwm/quickshell/pipewire: СНАЧАЛА покажи команду и бэкап, жди подтверждения.
4. Не придумывай API. Если не уверен (three-vrm, Quickshell-форк, LiteLLM, Qt WebEngine): читай актуальную документацию/исходники и ссылайся на них.
5. Секреты не хардкодь. Ключи только из окружения/secrets.env.
6. Делай маленькие коммиты, по одному на логический шаг.
7. Пиши тесты для парсера тегов, нарезки предложений, инициативы.
8. Все решения инициативы и расходы логируй с причиной.
9. Слушай только 127.0.0.1.
10. Если что-то не получается дважды, остановись и опиши проблему пользователю вместо бесконечных попыток.
